使い方

アプリとして入れる

Android（Chrome）：上の「アプリとして入れる」ボタン、または右上の︙ →「アプリをインストール」。
iPhone：共有ボタン（□に↑）→「ホーム画面に追加」（Safari・Chromeどちらでも可）。
入れると、専用アイコンからアドレスバーなしの全画面で開き、電波がなくても起動して本棚の本を読めます。ネットにつながっているときは、毎回最新の版に自動で更新されます。

ドライブをのぞく

ドライブ タブで、Googleドライブのフォルダを表紙つきで見られます。ZIPは目次と1枚目だけ、RARは先頭の数MBだけを取り寄せて表紙を作るので、大きなファイルでもすぐ並びます。タップすると保存せずにそのまま読めます。ZIPは読むページだけを取り寄せ、RARは先頭から読み込みながら、届いたページから表示しますRARの中に何冊分ものZIP・RARが入っているときも、全体はダウンロードせずに中の巻を表紙つきで並べ、選んだ巻だけを読み込みます（「ソリッド形式」のRARだけは、全体を読み込んでから開きます）。↓ で本棚に保存すると、ネットなしでも読めます。最初に一度だけ「準備・設定」が必要です。

端末から取り込む

本を追加 → ファイル選択画面の左上 ≡ → ドライブ などから、ZIP・RARを長押しで複数選んで 選択。

対応している形式

ZIP・CBZ・RAR・CBR（RAR5も可）と、それらが入れ子になった 二重圧縮。中に何冊分も入っているときは1冊ずつに分けて並べます。パスワード付き、分割RAR（part1, part2…）、7z には対応していません。

読むときの操作

ページの端を指で押さえたまま動かすと、本のようにめくれます。半分を超えたところで離すか、勢いよく払うとめくれ、手前で離すと戻ります。左右のタップでもめくれます。
上の 本のタイトル をタップするとタイトルの先頭10文字をコピーします。本棚・ドライブでは表紙を 長押し してもコピーできます。
左右の端を トンッ、ギュッ（2回目を押したまま）にすると、離すまでパラパラと連続でめくれ、だんだん速くなります。
中央タップでメニューの表示・非表示。2本指で広げると拡大、中央のダブルタップでも拡大。横向きにすると自動で見開き。Androidの「戻る」でひとつ前の画面へ。
2ページ分が1枚になった画像は、設定 →「2ページに分ける」で1ページずつ読めます。
上の 全体 ボタンで「全体 → 横幅 → 縦幅 → 縦スクロール」と表示を切り替えられます。横幅・縦幅では、タップするとページの中を少しずつ進み、端まで来ると次のページへ。本ごとに覚えます。
最後のページでさらに進むと、ファイル名の巻数から 次の巻 を探して案内します。

表紙を差し替える

本を開いて、表紙にしたい場面のページで 表紙 ボタンを押します。枠を指で動かし、2本指か右下の丸で大きさを変えて「この範囲を表紙にする」。「元の表紙に戻す」でいつでも戻せます。

タブレットとiPhoneで続きを読む

両方の端末でドライブにログインしていると、読んだ位置と表紙が自動で共有されます（ドライブ内の、このアプリ専用の隠しフォルダに保存。ドライブのファイル一覧には出ません）。片方で作った表紙はもう一方で作り直さないので、iPhoneでも軽く表示できます。同期の状態は本棚の上とドライブ画面に出ます。

ドライブのファイルを移動・削除する

ドライブ タブ →「準備・設定」で「移動・ゴミ箱に移せるようにする」をオンにして、ログインし直します。整理 を押してファイルやフォルダをタップで選び、下のバーから 移動（移動先のフォルダを選ぶ・その場で新しいフォルダも作れます）か ゴミ箱へ（もう一度押して確定）。直後なら「元に戻す」で戻せます。ゴミ箱のファイルは30日以内ならドライブから戻せます。ドライブから読んだ本は、最後のページで「ドライブのゴミ箱へ」も選べます。

保存について

本棚の本はこのページ用の保存領域（Chromeのサイトデータ）に入り、元のファイルとほぼ同じ容量を使います。Chromeで「サイトデータ」を削除すると消えます（ドライブの元ファイルは残ります）。いらない本は 整理 から削除できます。

ドライブにつなぐ準備（最初の一度だけ）

今開いている画面（claude.ai の中）からは、Googleにログインできません。下の手順でこのページを自分のサイトに置き、そちらで使ってください。

ドライブのファイルの削除

オンにすると、Googleに「ドライブのファイルの編集・削除」の許可を追加で求めます（次のログインで確認画面が出ます）。アプリが行うのは、選んだファイルを別のフォルダへ移すことと、ゴミ箱に移すことだけです。ゴミ箱のファイルは30日間、ドライブから元に戻せます。オフに戻すと、次のログインから閲覧のみの許可に戻ります。

Googleのクライアント ID

このページのアドレス（手順B-5で使います）：

A. このページをネットに置く（GitHub Pages・無料）

  1. github.com でアカウントを作ります。
  2. 右上の ＋ →「New repository」→ 名前を manga、Public にして作成。
  3. 「uploading an existing file」から index.html（このページのファイル）をアップロード →「Commit changes」。
  4. Settings → Pages で Branch を main / (root) にして Save。数分後に https://ユーザー名.github.io/manga/ で開けます。

B. Googleの許可を作る（Google Cloud・無料）

  1. console.cloud.google.com を開き、新しいプロジェクトを作ります。
  2. 「APIとサービス」→「ライブラリ」→ Google Drive API →「有効にする」。
  3. 「OAuth同意画面」→ 対象は 外部。アプリ名と自分のメールを入れて保存し、テストユーザー に自分のGmailを追加。
  4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は ウェブアプリケーション。
  5. 「承認済みのJavaScript生成元」に https://ユーザー名.github.io を追加して作成。表示された クライアントID をコピー。

C. タブレットで

  1. Chromeで https://ユーザー名.github.io/manga/ を開き、︙ →「ホーム画面に追加」。
  2. ドライブ タブ →「準備・設定」に、コピーしたクライアントIDを貼って「保存」→「Googleにログイン」。
  3. 「このアプリは Google で確認されていません」と出たら「詳細」→「（移動）」を選びます。自分専用のアプリなので問題ありません。

許可するのは「ドライブのファイルの閲覧」と「このアプリ専用の隠しフォルダ」（読んだ位置と表紙を端末間で共有するための場所）だけです。あなたのファイルの変更・削除や、共有設定の変更はできません。ただし、上の「移動・ゴミ箱に移せるようにする」をオンにしたときは、ファイルを移動したりゴミ箱に移したりする許可も加わります。ログインは1時間ごとに切れるので、そのときは「Googleにログイン」をもう一度押してください。本棚の中身はページのアドレスごとに別々です。
